# AI КОМАНДА — навыки недели 2

Три навыка для второй недели практикума **AI КОМАНДА** (COMANDOS AI): развернуть рабочее место, разобрать процесс на шаги и собрать первый навык из разговора.

## Навыки

**rabochee-mesto** — разворачивает рабочее место под конкретный процесс участника. Создаёт папки и служебные файлы, выводит из формулировки процесса список нужных материалов, задаёт уточняющие вопросы и раскладывает присланное по файлам контекста. Запускается фразой «Разверни моё рабочее место. Мой процесс: ...».

**razbor-processa** — разбирает рабочий процесс на 4-8 шагов, помечает каждый шаг как скрипт, навык, контекст или границу и рекомендует один шаг, из которого получится первый навык. Запускается фразой «Разбери мой процесс».

**sozdat-navyk** — собирает навык из только что состоявшегося разговора. К обычным разделам добавляет четыре наших: «Готово, если», «Как выглядит халтура», «Проверь перед выдачей», «После выдачи». Рядом собирает второй навык, проверяющий. Запускается фразой «Создай навык из того, что мы сделали».

## Установка

Скажите агенту в папке проекта:

```
Скачай навыки rabochee-mesto, razbor-processa и sozdat-navyk из репозитория
github.com/Comandosai/ai-komanda-skills и установи их в ~/.claude/skills/.
```

Или руками:

```bash
git clone https://github.com/Comandosai/ai-komanda-skills.git
cp -R ai-komanda-skills/rabochee-mesto  ~/.claude/skills/
cp -R ai-komanda-skills/razbor-processa ~/.claude/skills/
cp -R ai-komanda-skills/sozdat-navyk    ~/.claude/skills/
```

Перезапустите агента, чтобы навыки подхватились.

## Обезличивание данных

`rabochee-mesto/assets/maska.py` заменяет в файлах из `originaly/` телефоны, почту, ИНН, ОГРН, карты, счета, СНИЛС и паспорта на метки и кладёт копии в `vhod/`. `vozvrat.py` возвращает настоящие значения в готовые результаты из `vyhod/`. Соответствия хранятся в `slovar.json` на диске и никуда не отправляются.

Имена людей и названия компаний скрипт сам не находит. Их надо один раз вписать в `slovar.json`, в раздел `imena_i_nazvaniya`.

Скриптам нужен установленный Python. Для Word, Excel и PDF скрипт сам подскажет, какую библиотеку доустановить.
