# AI КОМАНДА, навыки недели 2

Три навыка для второй недели практикума **AI КОМАНДА** (COMANDOS AI): развернуть рабочее место, разобрать процесс на шаги и собрать первый навык из разговора.

Промты участника одинаковые на любой платформе. Разница платформ спрятана внутри навыков.

## Навыки

**rabochee-mesto** разворачивает рабочее место под конкретный процесс участника. Создаёт четыре логические области, копирует служебные файлы, записывает формулировку процесса, выводит из неё список нужных материалов и раскладывает присланное. Запускается фразой «Разверни моё рабочее место. Мой процесс: ...».

**razbor-processa** разбирает процесс на 4-8 шагов, помечает каждый как скрипт, навык, контекст или границу и рекомендует один шаг, из которого получится первый навык. Запускается фразой «Разбери мой процесс».

**sozdat-navyk** собирает навык из только что состоявшегося разговора. К обычным разделам добавляет четыре наших: «Готово, если», «Как выглядит халтура», «Проверь перед выдачей», «После выдачи». Рядом собирает второй навык, проверяющий. Запускается фразой «Создай навык из того, что мы сделали».

## Четыре логические области

- `kontekst` постоянные правила, справочники и образцы
- `vhod` файлы текущей задачи
- `vyhod` готовые результаты
- `originaly` необязательное хранение исходников с чувствительными данными

Там, где есть папки, это настоящие папки. Там, где файлы лежат плоским списком, это префиксы в именах: `kontekst-`, `vhod-`, `vyhod-`, `originaly-`. Участник в своих фразах всегда говорит `vhod`, `vyhod`, `kontekst`, а навык переводит это в устройство платформы сам.

## Установка

Скажите ассистенту в своей рабочей папке:

```
Установи комплект недели 2 из репозитория:
https://github.com/Comandosai/ai-komanda-skills

Если у тебя есть папки навыков, установи целиком rabochee-mesto,
razbor-processa и sozdat-navyk со всеми вложенными файлами.
Если файлы проекта лежат плоским списком, используй пакет chatgpt.
Не объявляй установку готовой, пока не проверил вложенные зависимости.
```

Полный текст промта лежит в `rabochee-mesto/assets/FRAZY.md`.

После установки обязательно откройте новый чат и спросите: «какие навыки у тебя сейчас есть». Ответ «установлено» в старом чате ничего не доказывает.

Руками, для Claude Code:

```bash
git clone https://github.com/Comandosai/ai-komanda-skills.git
mkdir -p .claude/skills
cp -R ai-komanda-skills/rabochee-mesto  .claude/skills/
cp -R ai-komanda-skills/razbor-processa .claude/skills/
cp -R ai-komanda-skills/sozdat-navyk    .claude/skills/
```

Перезапускать агента не нужно, навыки подхватываются на лету. Проверить список: команда `/skills`.

В Antigravity навыки лежат в `~/.gemini/config/skills/`. В Codex навыки тоже используют папки с `SKILL.md`; персональная установка по умолчанию находится в `~/.codex/skills/`.

Папка `chatgpt/` нужна средам без папок навыков. В проект загружаются сразу пять файлов: три инструкции, `shablon-proverki.txt` и `INSTRUKCII-PROEKTA.txt`. Основной маршрут для всех один: промт 1.

## Обезличивание данных

Нужно только там, где в файлах есть персональные, медицинские, платёжные или договорные данные. Публичную статью маскировать не надо.

Два способа, смешивать нельзя.

**Руками.** Копия файла, замена имён на метки, пары в `zamena.txt`, безопасная копия сразу в `vhod`.

**Скриптом.** `rabochee-mesto/assets/maska.py` заменяет в файлах из `originaly/` телефоны, почту, ИНН, ОГРН, карты, счета, СНИЛС и паспорта на метки и кладёт копии в `vhod/`. `vozvrat.py` возвращает настоящие значения в готовые результаты. Соответствия хранятся в `slovar.json` на диске и никуда не отправляются.

Имена людей и названия компаний скрипт сам не находит. Их надо один раз вписать в `slovar.json`, в раздел `imena_i_nazvaniya`.

Скрипты запускаются командой ассистенту `Запусти скрипт skripty/maska.py`. Двойной клик по файлу на большинстве компьютеров не сработает. Нужен установленный Python. Для Word, Excel и PDF скрипт сам подскажет, какую библиотеку доустановить.

## Критерий безопасности

Один, и он проверяется глазами: **в `vhod` нет данных, которые нельзя отправлять в модель.**
