# Карточки выбранной среды

Проверено по документации 16.09.2026. Это образцы, не обещание наличия функции в
любом клиенте. Сначала проверь доступные инструменты и локальные инструкции.
Не устанавливай новые платформы, плагины или платные сервисы ради режима В.

## Claude Code

Проектная карточка `.claude/agents/snabzhenec.md`:

```markdown
---
name: snabzhenec
description: Исполнитель роли Снабженец для дела, назначенного диспетчером.
---
Прочитай agenty/snabzhenec.md и указанные в нём навыки. Работай только над
переданными делом и попыткой, по договору передачи. Если вход недоступен,
остановись. Не запускай другие роли, верни результат диспетчеру.
```

Это минимальный синтаксис. Поле `tools` бездумно не копировать: если опущено,
права могут наследоваться. Для конкретной роли запиши только реально необходимые
инструменты по документации, проверь разрешения; внешняя отправка не разрешается
самим наличием инструмента. Модель по умолчанию наследуется. Проверь `/agents`,
при необходимости открой новый сеанс. Не требуй запуска субагентов из субагента.

Источник: https://code.claude.com/docs/en/sub-agents

## Codex

В клиенте с поддержкой пользовательских агентов проектная карточка
`.codex/agents/snabzhenec.toml`:

```toml
name = "snabzhenec"
description = "Исполнитель роли Снабженец для дела диспетчера"
developer_instructions = """
Прочитай agenty/snabzhenec.md и указанные в нём навыки. Работай только над
переданными делом и попыткой, по договору передачи. Нет входа: остановись.
Не запускай другие роли, верни результат диспетчеру.
"""
```

Проверь поддержку этой схемы установленной версией; не путай AGENTS.md с карточкой
сотрудника. AGENTS.md задаёт правила проекта. Если карточки не поддерживаются, но
есть инструмент дочернего исполнителя, диспетчер передаёт ему инструкцию прочитать
паспорт напрямую. Если нет и инструмента, только А/Б. Разрешения и модель не
ослабляй относительно настроек пользователя.

Источник: https://developers.openai.com/codex/subagents

## Gemini CLI

При доступной функции локальных агентов `.gemini/agents/snabzhenec.md`:

```markdown
---
name: snabzhenec
description: Исполнитель роли Снабженец для дела диспетчера.
kind: local
---
Прочитай agenty/snabzhenec.md и указанные в нём навыки. Работай только над
переданными делом и попыткой, по договору передачи. Нет входа: остановись.
Не запускай другие роли, верни результат диспетчеру.
```

Проверь загрузку через `/agents reload` и список агентов. Нужные инструменты
указывай по установленной версии и с минимальными правами; не предполагай, что
роль получает их все. Это НЕ инструкция для Gemini в браузере или Antigravity.

Источник: https://geminicli.com/docs/core/subagents/

## Чаты без общей папки

Паспорта и навыки остаются текстами. А выполняет один чат. В Б человек передаёт
файлы следующему чату; его запуск и перенос учитываются как работа человека.
Нельзя обещать, что следующий чат видит вложения предыдущего или лишён памяти
проекта. Выдай пакет входа и проверку: какие файлы получил, какие поля прочитал.
Наличие нескольких ответов от разных «ролей» в одном сообщении не доказывает В.
Схема и дашборд возможны как скачиваемые HTML-снимки; если нет файлового вывода,
покажи таблицу в чате. Живое обновление без подключённого источника не обещай.
