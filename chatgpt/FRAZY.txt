# Восемь промтов на всю неделю

Копируй отсюда. Придумывать ничего не надо.
Те же промты с кнопками копирования лежат в интерактивном гайде, ссылка в чате.

Промты одинаковые везде. Где бы ты ни работал, ты пишешь `vhod`, `vyhod` и `kontekst`,
а навык сам переводит это в устройство своей платформы.

---

## 1. Установить навыки

Один раз, в самом начале.

```
Установи комплект недели 2 из репозитория:
https://github.com/Comandosai/ai-komanda-skills

Сначала сам определи устройство своей среды.

Если у тебя есть папки навыков, скачай и установи целиком три папки со всеми вложенными файлами:
- rabochee-mesto вместе с папкой assets;
- razbor-processa;
- sozdat-navyk вместе с папкой references.

Не устанавливай только отдельные SKILL.md без вложенных файлов. Положи три папки туда, откуда твоя среда подхватывает навыки в новых чатах.

Если файлы проекта лежат плоским списком и папок навыков нет, скачай пять файлов:
https://raw.githubusercontent.com/Comandosai/ai-komanda-skills/main/chatgpt/rabochee-mesto.txt
https://raw.githubusercontent.com/Comandosai/ai-komanda-skills/main/chatgpt/razbor-processa.txt
https://raw.githubusercontent.com/Comandosai/ai-komanda-skills/main/chatgpt/sozdat-navyk.txt
https://raw.githubusercontent.com/Comandosai/ai-komanda-skills/main/chatgpt/shablon-proverki.txt
https://raw.githubusercontent.com/Comandosai/ai-komanda-skills/main/chatgpt/INSTRUKCII-PROEKTA.txt

Сохрани их как постоянные файлы проекта. Содержимое INSTRUKCII-PROEKTA.txt добавь в инструкции проекта.

Инструкцию выполняй целиком, а не пересказывай мне.
Если ссылка не открылась, скажи прямо, какая, и не выдумывай её содержимое.
Если сохранить навыки самостоятельно не можешь, не говори, что установка завершена. Выдай файлы и скажи одним действием, что мне сделать руками.

Работай без лишних переспросов: если данных хватает, действуй сам. Спрашивай только то, без чего нельзя продолжить. Не делай без моего подтверждения только необратимое: удаление файлов, отправку наружу, публикацию.

Когда установишь, назови место каждого из трёх навыков и процитируй по одной строке из каждого.
Отдельно подтверди, что видишь файл FRAZY.md внутри assets у rabochee-mesto и файл shablon-proverki.md внутри references у sozdat-navyk. В плоской среде вместо этого подтверди, что видишь shablon-proverki.txt и INSTRUKCII-PROEKTA.txt.
```

Потом открой новый чат и напиши: «какие навыки у тебя сейчас есть». Он должен назвать все три.
Не назвал, значит установка не прошла, и дальше идти бессмысленно.

---

## 2. Развернуть рабочее место

```
Разверни моё рабочее место.
Мой процесс: [твоя формулировка с первой недели]
```

Свои материалы положи в рабочую папку заранее, навык разложит их сам:
пять настоящих входящих, правила или регламент, два своих хороших результата и один плохой.

Вход у тебя не файл? Сначала сделай из него файл. Переписку скопируй в текстовый файл,
звонок расшифруй, данные из системы выгрузи в XLSX, CSV или PDF, устную просьбу надиктуй.

---

## 3. Разобрать процесс

Новый чат.

```
Разбери мой процесс.
```

---

## 4. Сделать работу разговором

Новый чат. Сначала положи один настоящий файл в `vhod`.

```
Возьми файл [точное имя файла] из vhod и сделай по нему [коротко: что именно надо получить].
Если такого файла нет, скажи об этом прямо и не бери другой.

Прочитай все относящиеся к этой задаче правила, справочники и образцы из kontekst.
Если нужных данных нет, скажи, чего именно не хватает, и не выдумывай.

Готовый результат сохрани отдельным файлом в vyhod, а не только покажи в чате.
```

Дальше разговаривай. Не нравится результат, объясни словами, что не так.
Не переписывай сам, объясняй. Три-четыре круга.

---

## 5. Создать навык

В том же чате, где делал работу.

```
Создай навык из того, что мы сейчас сделали.
```

Он задаст два вопроса. На выходе два навыка: твой и `proverka-имя-твоего-навыка`.
Запиши себе имя навыка, оно нужно дальше.

---

## 6. Запустить навык

Новый чат на каждый прогон.

```
Запусти мой навык [имя навыка] на файле [точное имя файла] из vhod.
Если такого файла нет, скажи об этом прямо и не бери другой.
Работай строго по навыку. Прочитай относящийся к этой задаче контекст. Ничего не выдумывай сверх.
Готовый результат сохрани отдельным файлом в vyhod.
```

---

## 7. Обновить навык

После каждого чернового прогона.

```
Обнови мой навык [имя навыка].
Вот что мне не понравилось в этом прогоне: [одна конкретная проблема].
Покажи точную строку, которую хочешь добавить или изменить, и дождись моего согласия.
После согласия обнови навык и запиши этот прогон одной строкой в zhurnal.
```

---

## 8. Проверить пять результатов

Один раз, в конце недели. Новый чат.

Сначала убери черновики:

```
Убери черновые результаты из vyhod в chernoviki. Оставь vyhod пустым под пять зачётных.
```

Потом пять зачётных прогонов промтом 6. Потом проверка:

```
Запусти проверяющий навык proverka-[имя навыка] на пяти результатах zachet-01, zachet-02, zachet-03, zachet-04 и zachet-05 из vyhod.
Критерии бери из раздела «Готово, если» моего навыка [имя навыка].
Разбирай каждый результат отдельно. По каждому пункту дай ДА, НЕТ или НЕ ПРОВЕРИТЬ и дословную цитату.
В конце сводка: сколько из пяти получили ГОТОВО К ОТПРАВКЕ.
```

## Если в файлах есть чувствительные данные

Персональные, медицинские, платёжные, договорные. Тогда обезличивай до того, как отдать модели.
Два способа, выбери один на всю неделю и не смешивай.

**Руками.** Сделай копию, замени имена на метки вида КЛИЕНТ-А, пары запиши
в файл `zamena.txt`, безопасную копию положи в `vhod`. В конце верни значения обратно по `zamena.txt`.

**Скриптом**, работает там, где есть папки и Python.

```
Запусти скрипт skripty/maska.py
```

Исходник кладёшь в `originaly`, имена людей и компаний вписываешь один раз
в `skripty/slovar.json`, безопасная копия появляется в `vhod`.
В конце: `Запусти скрипт skripty/vozvrat.py`

Если чувствительных данных нет, прятать нечего. Клади файл сразу в `vhod`.

---

## Три правила, которые нельзя нарушать

1. Каждый прогон в новом чате И на новой задаче.
2. Правишь не результат, а сам файл навыка.
3. Метрика это не минуты, а сколько из пяти ты отправил бы, не тронув ни слова.
