# Отчёт практикума

Для недели 6 прочитай [references/nedelya-6.md](references/nedelya-6.md) полностью;
не применяй к ней требования пяти повторов недели 5.

Номер недели бери из запроса и контекста, не спрашивай повторно. Если определить
нельзя, спроси только номер недели. Для недели 5 прочитай references/nedelya-5.md
целиком; правила недели 3 к ней не применяются. Для недели 3 прочитай
references/nedelya-3.md. Для другой недели используй её явно предоставленную
инструкцию; если её нет, попроси её, не подставляй неделю 3.

Читай только доступные материалы. «Диск» в инструкции означает также загруженные
файлы и этот разговор. Без сохранения файлов выдай весь отчёт в чат. Никакой
отправки отчёта наружу. Не запускай рабочие роли и не исправляй проект при сборе.
