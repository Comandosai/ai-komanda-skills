# Контракт стыков

Здесь записано, чем один навык передаёт работу другому: как называется файл
и какие поля в нём обязательны. Второй навык читает эту же запись и отказывается
работать, если вход пришёл не по контракту.

Контракт лежит в одном месте. Оба навыка ссылаются сюда, а не хранят копию у себя,
иначе через две правки записи разъедутся.

---

## Мои стыки

```
НОМЕР-ШАГА и имя

  отдаёт: [какому навыку]
  файл: [точное имя файла]
  обязательные: [поля, без которых работать нельзя]
  необязательные: [поля, которые могут быть, а могут не быть]
```

Пустое поле помечается словом «нет», а не пропускается.
Если результат шага не читается глазами, описывай спутник, а не сам файл.

*Заполняется на шаге 3 и шаге 4. Навык `sozdat-navyk` спрашивает про соседа
по цепочке и дописывает строку сюда сам.*

# ПРИМЕР. Так это выглядит заполненным

Ниже чужой процесс, просто чтобы был виден формат. Свои стыки пиши выше.

## Случай 1. Результат текстовый

```
01-parametry

  отдаёт: raschet-zakaza
  файл: 01-parametry.md
  обязательные: chto, skolko, razmery
  необязательные: srok, kuda
  пустое поле помечается словом «нет», а не пропускается
```

Тут всё просто: файл один, следующий навык читает его целиком.

## Случай 2. Результат нетекстовый, рядом спутник

```
02-raschet

  отдаёт: podgotovit-otvet
  файл: 02-raschet.xlsx
  спутник: 02-raschet.md
  обязательные поля спутника: variant, cena, srok_postavki
  необязательные поля спутника: kommentariy
```

Таблицу, картинку, скан, аудио следующий навык глазами не читает. Поэтому рядом
кладётся текстовый спутник с тем же номером шага. Контракт описывает спутник,
сам файл в контракте только назван.

Правило то же для видео, аудио, скана, архива: есть нетекстовый результат,
значит есть спутник.
