# Шесть фраз на всю неделю

Копируй отсюда. Придумывать ничего не надо.

---

## 1. Развернуть рабочее место

Один раз, в самом начале.

```
Разверни моё рабочее место.
Мой процесс: [твоя формулировка с первой недели]
```

---

## 2. Разобрать процесс

Новый чат.

```
Разбери мой процесс.
```

---

## 3. Сделать работу

Новый чат. Сначала положи один настоящий файл в папку vhod.

```
Возьми файл vhod/[имя файла] и [что с ним надо сделать].
```

Дальше просто разговаривай. Не нравится результат, объясни словами,
что не так и почему. Не переписывай сам, объясняй. Три-четыре круга.

---

## 4. Создать навык

В том же чате, где делал работу.

```
Создай навык из того, что мы сделали,
по правилам из shablony/pravila-navyka.md
```

Он задаст два вопроса. Отвечай голосом.
На выходе получишь два файла: навык и его проверяющий.

---

## 5. Обновить навык

После каждого чернового прогона, когда что-то поправил.

```
Обнови навык.
```

---

## 6. Проверить

Новый чистый чат, в конце недели, сразу на все пять результатов.

```
Проверь эти результаты.
```

---

# Три правила, которые нельзя нарушать

**Каждый прогон в новом чате.** Иначе меряешь память чата, а не навык.

**Каждый прогон на новой задаче.** Одну и ту же гонять бессмысленно.

**Критерии складываются по ходу, а не пишутся заранее.** Пока не увидел,
как оно провалилось, напишешь общие слова.
