# Задание недели 2

Восемь шагов, около двух с половиной часов.
Порядок менять нельзя.

```
0. Поставить три навыка                             15 мин
   пустая рабочая папка, промт 1, потом проверка в новом чате

1. Развернуть рабочее место                         20 мин
   промт 2, дальше отвечаешь на вопросы и грузишь материалы

2. Разобрать процесс, выбрать ОДИН шаг              20 мин
   новый чат, промт 3

3. Сделать работу разговором                        20 мин
   новый чат, один настоящий файл в vhod, промт 4, 3-4 круга правок
   не переписываешь сам, объясняешь словами

4. Создать навык                                    10 мин
   промт 5, два вопроса, на выходе два навыка

5. Три черновых прогона с докруткой                 35 мин
   каждый в НОВОМ чате, каждый на НОВОЙ задаче
   промт 6, потом промт 7

6. Пять зачётных прогонов и одна проверка           40 мин
   сначала убрать черновики, потом пять раз промт 6, потом промт 8

7. Сдать                                             5 мин
```

Всего восемь запусков навыка: три черновых и пять зачётных.
В метрику идут только пять зачётных.

## Маршрут файла

```
безопасный файл  →  vhod  →  навык  →  vyhod
```

Если в исходнике есть чувствительные данные, обезличь его до `vhod`.
Руками с файлом `zamena.txt`, либо через `originaly` и скрипт `maska.py`.
Способы не смешивай. Нет чувствительных данных, клади файл сразу в `vhod`.

## Что сдаём

Строка в общую таблицу:

```
процесс · занимало примерно N минут · теперь примерно M ·
принято без правок X из 5
```

Время навскидку, по ощущению. Секундомер не нужен.

И три файла: сам навык, его проверяющий и карту процесса.
Карта нужна на неделях 3 и 4, поэтому сдаём её сразу.

## Неделя закрыта, если

- рабочее место развёрнуто, контекст не пустой
- в образцах лежат настоящие файлы: пять входящих, два хороших, один плохой
- карта процесса есть, один шаг помечен выбранным
- в навыке есть все четыре наших раздела
- рядом лежит проверяющий `proverka-имя-навыка`
- в `vhod` нет данных, которые нельзя отправлять в модель
- в `vyhod` пять зачётных результатов, черновые не считаются
- в журнале видно, что навык обновлялся минимум дважды

Последний пункт главный. Он показывает, что ты докручивал навык,
а не просто прогнал промпт пять раз.
