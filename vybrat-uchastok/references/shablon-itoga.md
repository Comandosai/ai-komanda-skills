# Шаблон итогового файла

Собери файл `vybor-uchastka/itog-vybora-uchastka.md` строго в этом порядке. Пустые разделы не выбрасывай, пиши «нет». Цифры, которых человек не назвал, не выдумывай. Внутри документа заголовки только у шести разделов, реплики переписки идут жирными метками `**Человек:**` / `**Ассистент:**`.

```markdown
# Выбор участка: ‹имя›, ‹компания или проект›

Дата: ‹ДД.ММ.ГГГГ›

## 1. Кто я и что для меня польза

‹Чем занимается, компания, роль, тип: собственник / сотрудник / интегратор (для себя или клиента) / запускает новое. 2-4 строки.›

**Польза для меня:** ‹фраза, которую человек подтвердил на шаге 2›

## 2. Выбор

**Основное дело:** когда ‹X›, делаем ‹Y›, получаем ‹Z›
- Почему: ‹одна-две фразы, со ссылкой на пользу›
- Рейтинг ‹N›, ‹часов› ч в месяц, ‹сумма› ₽ в месяц ‹(прогноз, если есть; если цену часа не назвали, пиши «стоимость часа не названа»)›
- Сделано хорошо, если: ‹критерий словами человека›

**Запасное дело:** когда ‹X›, делаем ‹Y›, получаем ‹Z›
- Почему: ‹одна фраза›
- Рейтинг ‹N›, ‹часов› ч в месяц, ‹сумма› ₽ в месяц

‹Если человек выбрал не первое по рейтингу, одной строкой: почему.›

## 3. Все дела

| № | Дело | Итог | Польза | Уверенность | Повторяемость | Лёгкость | Желание | Рейтинг | Ч/мес | ₽/мес |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | ‹формулировка› | основное | 5 | 4 | 4 | 4 | 5 | 51 | 12 | 18 000 |
| 2 | ‹…› | запасное | … | … | … | … | … | … | … | … |
| 3 | ‹…› | оценено | … | … | … | … | … | … | … | … |
| 4 | ‹…› | вычеркнуто: стоп 1, ‹причина› | | | | | | | | |
| 5 | ‹…› | без AI, см. раздел 4 | | | | | | | | |
| 6 | ‹…› | не вошло в восьмёрку | | | | | | | | |

Пометки к оценкам: ‹по каким оценкам «есть примеры», остальные «по памяти»›.
Стоимость часа: ‹сколько и чей час›.
Решения вопреки стопу: ‹если были, словами человека›.

## 4. Можно упростить уже сейчас

- ‹дело›: ‹что сделать без AI: формула, шаблон, убрать двойной ввод, перестать делать›

## 5. Досье бизнеса

‹Всё, что человек рассказал, его словами, по темам: чем занимается бизнес, клиенты, команда и кто что делает, системы и программы, где лежат данные, что выматывает, что пробовали раньше. Не сокращай до общих слов, сохраняй конкретику: цифры, названия, имена ролей.›

## 6. Переписка

‹Полный текст perepiska.md, без сокращений и пересказа.›
```

Перед сохранением проверь:

- в разделе 3 все дела из склеенного списка;
- у каждого вычеркнутого есть номер стопа и причина;
- рейтинги посчитаны по формуле из `ocenka.md`;
- часы и деньги только у топ-3;
- переписка целиком.
