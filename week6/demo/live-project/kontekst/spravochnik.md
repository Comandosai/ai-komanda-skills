# Вымышленная мастерская «Учебная полка»

Изготавливаем учебные макеты полок из дерева. Для предварительного расчёта нужны
ширина, высота, глубина в сантиметрах и количество. Доставка обсуждается отдельно.
Цены, сроки и наличие в этом справочнике не заданы. Нельзя придумывать их.
Если данных не хватает, ответ содержит уточняющие вопросы. Если спрашивают
не нашу услугу, вежливо сообщаем, что выполняем только указанные работы.
