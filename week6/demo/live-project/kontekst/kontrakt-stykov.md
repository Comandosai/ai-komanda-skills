# Контракты навыков

## Анализ заявки

Отдаёт: Markdown с фактами, пробелами, вопросами.
Файл: 01-analysis.md в папке текущей попытки.
Обязательные: источник, запрошенная услуга, все известные параметры, неизвестное.
Необязательные: ничего.

## Ответ

Отдаёт: черновик ответа без внешней отправки.
Файл: 02-answer.md в папке текущей попытки.
Обязательные: факты не противоречат заявке и справочнику, вопросы по пробелам.
Необязательные: приветствие.

Раздел стыков между ролями создаётся при настройке, старые записи сохраняются.
