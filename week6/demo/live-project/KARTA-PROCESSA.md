Одна заявка -> аналитик выделяет факты и пробелы -> автор готовит черновик
ответа -> проверка по первоисточнику -> владелец принимает версию.

Конечный результат: черновик ответа и проверка, не отправленное сообщение.
Один вход: один Markdown из vhod/. Постоянный источник: kontekst/spravochnik.md.
