# Живая демонстрация: ответы мастерской

Это исходная папка для работы настоящего ИИ, не симулятор. Данные вымышлены.
Две роли уже описаны, но независимые прогоны ещё НЕ выполнены. Диспетчера нет.
Не называйте роли проверенными до адресной проверки каждого шага.

1. Скопируйте эту папку в отдельное рабочее место через файловый менеджер.
2. Откройте её проектом в своей среде. Навык svyazat-komandu должен быть доступен
   отдельно из комплекта недели 6. Не запускайте simulator.py вместо агента.
3. В новом чате попросите: «Проверь отдельно обе роли на входе vhod/trial-1.md.
   Прочитай их паспорта и навыки. Покажи реальные результаты и проверки.
   Если отдельные исполнители недоступны, скажи об этом». Сохраните свидетельства.
4. Новый чат: «Свяжи существующие роли этого проекта в один запуск. Используй
   svyazat-komandu. Покажи маршрут и изменения. Ничего наружу не отправляй».
5. Согласуйте запись диспетчера. Новый чат: «Запусти всю команду. Пробный прогон.
   Вход: vhod/trial-1.md». После результата дайте конкретную обратную связь.
6. Отдельной командой согласуйте сохранение улучшений. Второй пробный вход
   vhod/trial-2.md выполняется новым чатом.
7. Для финальных дел используйте final-1.md, final-2.md, final-3.md, каждый новым
   чатом и только после отладки. Подготовленная папка не является зачётом.

Для одной роли: согласованно объедините анализ и ответ в один паспорт и проверьте
обе операции. Для трёх: добавьте отдельного контролёра с доступом к исходной заявке
и справочнику. Одна операция не становится независимой проверкой от переименования.

Внешние подключения, ключи, сервер и расписание отсутствуют. Ответ только черновик.
Владелец должен явно принять конкретную версию; отправка клиенту вообще вне участка.
