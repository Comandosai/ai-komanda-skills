# Правила демонстрационного проекта

Работай только с вымышленными заявками этой папки. Не используй сеть, ключи,
отправки и публикации. Читай карту процесса, паспорта и справочник.
Не обещай цену, срок или наличие без данных. Не называй самопроверку независимой.
Результаты и проверки разных попыток не перезаписывать. Источники не изменять.
Диспетчер пока не настроен. Не выдавай наличие файлов за проверенный процесс.
