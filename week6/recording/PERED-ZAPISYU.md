# Перед записью: контрольный лист

## Можно готовить локально

- Открыть гайд, проверить масштаб и читаемость, кнопки копирования.
- Распаковать комплект в отдельную учебную папку.
- Пройти настройку связки на live-project; не подменять её simulator.py.
- Подготовить три разных безопасных входа и один неполный.
- Сделать снимок папки перед каждым видео. Ключи в снимки не входят.
- Зафиксировать модель, среду, дату и версию файлов. Провести репетицию с хронометражем.
- Открыть будущую HTML-защиту без сети; шаблон с квадратными скобками не сдавать.

## До съёмки VPS/Hermes нужен живой стенд

В этой поставке сервер не куплен и не настроен. Нужен выделенный учебный VPS
либо явно разрешённая тестовая машина, выбранный доступный провайдер модели,
расходный лимит и при необходимости личный тестовый Telegram-бот.
Не использовать существующий рабочий Hermes-библиотекарь для учебных опытов.

Пройти VPS-HERMES.html: проверить установку, вход как team, инструменты, безопасный
ручной запрос, роль и проверку, крон с рабочей папкой, фактический запуск после
выхода из SSH, паузу, повтор, согласованную перезагрузку. Сохранить подтверждения
без ключей. Только после этого говорить на видео «проверено на этом стенде».

## Таблица доказательств для заполнения ведущим

Для каждого видео: дата; среда/версия; вход; путь результата; путь проверки;
что выполнено живьём; что является учебной симуляцией; что осталось непроверенным.
Незаполненная таблица не является свидетельством успешного запуска.

## Что не обещать

- Любой процесс переносится на Linux без адаптации.
- Подписка на чат оплачивает API и сервер.
- Три дела гарантируют надёжность.
- Сторож и механик могут менять правила без владельца.
- Документация или симулятор заменяет серверный прогон.
- Весь дополнительный VPS/виджет/несколько API помещается в основной лимит практики.

Российский стек без VPN требует отдельного проверенного провайдера и способа оплаты.
До такого теста это открытая проверка, не готовое обещание для всех участников.
